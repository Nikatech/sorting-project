# Три сортировки — учебный многофайловый проект

Программа читает одну строку целых чисел, предлагает выбрать алгоритм и сортирует числа по возрастанию. Поддерживает отрицательные числа и повторы.

## Файлы

| Файл | Назначение |
|---|---|
| main.cpp | Ввод чисел, выбор алгоритма, вывод результата |
| sorts.hpp | Объявления трёх функций — общий интерфейс |
| bubble.cpp | Пузырёк: сравнение и обмен соседних элементов |
| selection.cpp | Выбор: поиск минимума в неотсортированной части |
| insertion.cpp | Вставки: перенос очередного элемента на место |

Каждая функция получает вектор по ссылке и изменяет его. Заголовок сообщает компилятору имена функций и их параметры. Реализации находятся в отдельных .cpp; линковщик связывает их с вызовами из main.cpp.

## Быстрая сборка в Linux (g++)

Из папки проекта:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp bubble.cpp selection.cpp insertion.cpp -o sorter
./sorter
```

Пример ввода: первая строка `5 -2 5 0 1`, вторая строка `3`. Результат: `-2 0 1 5 5`.

## Раздельные этапы сборки для лабораторной

### 1. Препроцессинг

```bash
g++ -std=c++17 -E main.cpp -o main.ii
g++ -std=c++17 -E bubble.cpp -o bubble.ii
g++ -std=c++17 -E selection.cpp -o selection.ii
g++ -std=c++17 -E insertion.cpp -o insertion.ii
```

### 2. Компиляция и ассемблирование в объектные файлы

```bash
g++ -std=c++17 -Wall -Wextra -pedantic -c main.ii -o main.o
g++ -std=c++17 -Wall -Wextra -pedantic -c bubble.ii -o bubble.o
g++ -std=c++17 -Wall -Wextra -pedantic -c selection.ii -o selection.o
g++ -std=c++17 -Wall -Wextra -pedantic -c insertion.ii -o insertion.o
```

Флаг -c объединяет компиляцию и ассемблирование, но останавливает сборку до линковки. При желании эти два действия можно разделить: `g++ -std=c++17 -S main.ii -o main.s`, затем `g++ -c main.s -o main.o`.

### 3. Линковка

```bash
g++ main.o bubble.o selection.o insertion.o -o sorter
```

### 4. Запуск

```bash
./sorter
```

Файл sorter — готовая программа. Картинки или другие ресурсы ей не требуются. Для передачи другому человеку нужна совместимая ОС, архитектура и системные библиотеки.

## Что проверить самостоятельно

Для каждого из трёх алгоритмов попробуй: `5 -2 5 0 1`, уже отсортированный список, обратный порядок и одно число. Введи букву вместо числа и неверный номер алгоритма — программа должна показать ошибку.
